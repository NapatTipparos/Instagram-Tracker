# Instagram Follower Tracker

A Java-based application that analyzes Instagram follower relationships using set theory. It applies intersection, difference, and union operations to identify mutual followers, find accounts that do not follow back, and simplify comparisons between follower lists.

## How It Works

1. **Download Instagram Data:** Download your Instagram account information, including your followers and following lists.
2. **Upload Files:** Upload the downloaded files, which are usually in TXT or CSV format.
3. **Clean the Data:** The code removes unnecessary information, such as dates, times, and hours, keeping only the usernames.
4. **Save Usernames:** The cleaned usernames are stored in a new TXT file created by the code as the starting point for the analysis.
5. **Analyze Follower Relationships:** The code applies intersection, difference, and union operations to identify mutual followers and accounts that do not follow back.
6. **Display Results:** The output is displayed after the analysis is complete.
